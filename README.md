

\# Campus Bites



\## Campus Cafeteria Information Website



Campus Bites is an informational website for a fictional

university cafeteria. It helps students and staff explore

food menus, daily deals, ordering instructions and feedback.



\## Technologies



\- HTML5

\- CSS3

\- Git

\- GitHub



\## Website Pages



1\. Home

2\. Menu

3\. Daily Specials and Deals

4\. How to Order

5\. Feedback and Contact



\## Project Structure



\- src/ - Contains all HTML pages.

\- styles/ - Contains the shared CSS file.



\## Development Workflow



The team uses Git and GitHub for collaborative development.



\- main: Production branch

\- develop: Active development branch

\- feature branches: Individual page development

\- release/v1.0: Testing and release preparation
